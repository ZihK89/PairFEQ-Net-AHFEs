Supporting information for the PairFEQ-Net work on **absolute hydration free energy calculations**.

`./data` contains the molecular input files, the **QM reference datasets** calculated at the **B3LYP-D3/6-31+G\*** level for model training, and the **reduced free energy matrices** used for the final free energy difference calculations.

`./figs` contains the scripts used to reproduce the figures.

`./example` contains example PairFEQ-Net scripts and MLP models for running an enhanced ME ML/MM simulation in aqueous solution.
